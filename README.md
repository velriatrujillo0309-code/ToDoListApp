# ToDoListApp

Aplicacion movil desarrollada en Android Studio usando Java, SQLite y RecyclerView.

El proyecto consiste en un gestor de tareas donde el usuario puede crear, buscar, editar y eliminar tareas. Toda la informacion queda almacenada localmente en SQLite para que las tareas no se pierdan al cerrar la aplicacion.

La aplicacion cuenta con:

- Registro de tareas
- Busqueda de tareas por titulo
- Edicion de tareas
- Eliminacion de tareas
- Lista dinamica usando RecyclerView
- Persistencia de datos con SQLite

Tecnologias utilizadas:

- Java
- Android Studio
- SQLite
- RecyclerView
